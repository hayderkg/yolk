# Changelog

## 1.4.0 beta

- Renamed from Port Dog to Yolk, with a fried-egg menu bar symbol. The bundle identifier and preferences are unchanged.
- English interface.
- Keyboard-first panel: type to filter, arrow keys to select, Return to open, ⌘C to copy the address, ⌘⌫ to stop.
- Clicking a row opens the service; clicking the port copies its address.
- Rows show the shortened command line and uptime. Row actions appear on hover or selection, and row dividers are gone.
- Container ports published by Docker-compatible engines show the container name and image, and stop the container rather than the engine.
- "Stop everything" per group, with confirmation.
- Open a project in Finder, an installed editor or a terminal from the context menu.
- Optional global shortcut to open the panel.
- A dot on the menu bar icon, and on the rows, for ports that appeared since the panel was last open.
- Ports arriving and leaving fade in and out; small motion on refresh, favorites, the counter, search and settings. Reduce Motion is respected.
- Overlay scrollbars regardless of the system setting.
- Fixed unreadable text in light mode while the system is in dark mode, and the filter icon ignoring the palette.

## 1.3.0 beta

- Port Dog identity, original retro sausage mascot, application icon and optical menu-bar template symbol.
- Compact settings inside the existing panel (⌘,).
- System/light/dark appearance, translucent/solid surfaces, and four palettes.
- Configurable refresh interval and native launch-at-login controls in settings.
- MIT license, English/Spanish documentation, privacy notes, contribution and release guides.
- GitHub CI for tests and universal development artifacts; optional notarized release script.
- Existing Local Ports preferences remain compatible.

Notifications, automatic updates and Homebrew distribution are future work.

## 1.2.0

Search, persistent favorites/hidden services, network scope, optional login item, pinned headers, subtle transitions and top-anchored panel resizing.

## 1.1.0

Service groups, project names, application icons, local favicons and initials.

## 1.0.0

Native TCP listener inspection, browser actions and normal/forced process termination.
