# Brand assets

The logo (`Brand/logo.svg`, a fried egg drawn as one continuous line) was supplied by the project author. The app draws its two paths directly, coloured by the active palette, from `Sources/LocalPorts/BrandAssets.swift`. The application icon (`Sources/LocalPorts/Assets/AppIcon.png`) is the same drawing on a cream tile with a yellow yolk, masked to the macOS icon shape. The menu-bar symbol is that same line drawn as a template image at menu-bar scale, slightly thickened so it stays legible. The user's visual references were style inspiration; their images are not included in this repository.
